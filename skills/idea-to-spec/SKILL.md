# Idea to Spec

1. Separate the goal from the means: what the user ultimately wants, and how they plan to do it.
2. Clarify the goal: confirm anything ambiguous with the user.
3. Find the constraints: the facts that reaching this goal cannot get around.
4. Test the means: check whether the means fits these constraints, and whether an existing solution already meets the goal.
5. Converge: propose a spec and ask the user to approve it.

Write no code until the user approves.
