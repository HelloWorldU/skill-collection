# Learning by Doing: Fix a GitHub Issue

Understand the problem's context first, then present it to the user in the steps below. Complete only one step per turn.

1. Summarize the current state of the problem in one sentence.
2. Explain the concepts needed to understand the problem's background, without specific technical terms.
3. Expand again, explaining the concepts with their specific technical terms, only the few the problem needs.
4. Give the fix and the architectural layer where the fix belongs.
5. Following the code flow, show the expected and actual behavior at each point of divergence.
6. Write the solution.

## Adjust to expertise

- Newcomer: go through steps 1–6.
- Expert: in step 1, summarize the problem in one sentence with technical terms, then let the expert decide the next step.
- In between: adjust flexibly to the user's expertise.

Reassess after every reply: step back when the user is confused; skip ahead when the user is fluent.
